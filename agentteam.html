WHY

为什么是一家公司，而不是又一个 Agent 列表

市面上多数「AI Agent 框架」只是单 Agent 工具：一张扁平列表、几个到几十个 Agent、没有技能体系、没有测试、没有健康检查。agentteam 的答案是把 Agent 组织成公司 —— 有领导层、有部门、有汇报线、有验收。以下为项目 README 中的真实对照：

FLOW

一句话之后，公司怎么动起来

以 AGENCY.md 里的真实任务「帮我做个 SaaS」为例，六步走完全程。三条铁律贯穿始终：跨 2+ 部门必走 COO、重大技术决策必走 CTO、战略问题必走 CEO。

01
📥 下达任务
用户一句话：「帮我做个 SaaS」。不用点名任何 Agent，公司自己接活。
02
👑 CEO 评估
评估战略价值、优先级与资源，批准立项。
03
📋 COO 拆解派发
把任务拆成原子任务，按部门派单给各部门主管。
04
🏢 部门主管选将
PRD 出架构 / 后端 / 前端 / 部署，DES 出 UI/UX 与品牌，MKT 出落地页与文案，SAL 出定价，CSM 出客服话术。
05
🔍 COO 监控
5 字诀「拆派检核收」全程跟踪质量与进度。
06
✅ CEO 验收归档
验收战略目标达成，交付物归档知识库、项目复盘。
