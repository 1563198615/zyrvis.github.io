EatElite 隐私政策

更新日期：2026 年 9 月 27 日

EatElite（“本应用”）由 ZYRVIS 提供。本政策说明本应用如何处理与你的饮食记录有关的数据。

本应用处理的数据

本应用保存你输入或确认的饮食、营养、饮水和偏好数据。饮食与饮水记录在 iCloud 容器可用时写入你的 Apple 账户对应的 iCloud 文档容器；iCloud 不可用时保存在设备上。你可以导入或导出 JSON 备份，导出文件由你选择的位置管理。

Apple 健康

只有在你授权后，本应用才会读取 Apple 健康中的基础能量、活动能量、饮水和体重，或写入饮水、膳食能量及营养素记录。健康数据用于应用内的记录与回顾，不用于广告、营销或出售给第三方。授权可在系统设置中管理。

AI 图片识别与自定义 API

照片首先用于设备上的文字和条码识别。只有你明确点击“使用 AI 识别这张照片”后，照片才会发送到你选择的 AI 服务；选择自带 API 时，照片及识别提示会发往你配置的服务地址，由该服务商按其隐私政策处理。照片不包含在本应用的 JSON 备份中。识别结果中的份量与热量为估计值，保存前请核对。

官方订阅服务尚未开放。正式开放前，我们会在本页公布官方网关和上游视觉模型的运营方、处理地区及数据保留信息。官方服务将使用 Apple 签名交易信息核验订阅；网关只保存原始交易 ID 的摘要、UTC 日期和每日调用次数，并在后续请求时清除 30 天前的计数。

条码查询与密钥

检测到条码并查询包装食品时，条码会发送至 Open Food Facts。自带 API 密钥保存在设备钥匙串中，不包含在 JSON 备份中。

数据存储与控制

你可以在应用中删除单条记录，也可以在“设置 → 数据与备份”清空当前本机或 iCloud 饮食和饮水记录。已导出的备份文件及写入 Apple 健康的记录需要分别管理。可在应用中移除自带 API 密钥。正式服务开放后，如需处理网关配额记录，请通过下方邮箱联系。
