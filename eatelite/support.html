EatElite 支持

EatElite 帮你记录饮食、营养和饮水，并通过拍照识别辅助完成一餐记录。

本应用提供的营养值是估计结果，不是医学检测。饮食记录不能用于疾病诊断或治疗建议。如有健康问题请咨询医生或注册营养师。

开始使用：AI 识别需要你自己配置

EatElite 的拍照识别功能需要你提供一个 AI 服务。本应用不提供官方 AI 订阅，也不在应用内内置任何服务器密钥。这样做是为了让照片的去向始终由你自己决定。

如果你只是想手动记录饮食、饮水和营养，完全不需要配置任何东西——「记一餐」按钮可以直接用。

配置步骤

  • 前往任意 AI 服务商开放平台注册账号，获取 API Key。你可以选择 MiniMax、阿里云百炼（通义千问）、智谱 GLM、DeepSeek、Kimi，或任意兼容 OpenAI Chat Completions 协议的服务。
  • 打开 EatElite「设置 → AI 与订阅」。
  • 选择服务商，填写基础地址、视觉模型名称和 API Key。
  • 可点击「测试连接（仅文本）」检查服务配置。
  • 只有你主动配置了服务地址、模型和凭据并使用拍照识别时，照片才会发送到所选服务商。

如果你不打算使用 AI 拍照识别，本应用仍然可以在本机完成营养标签 OCR 和条码识别；查询条码商品资料时会向 Open Food Facts 发送条码数字。

常见问题

照片发出去会怎样？

照片会先在设备上压缩（长边最大 2048 像素，JPEG 质量 0.88），然后发送给你所选的 AI 服务商，附带识别用的提示词。你的饮食记录、API Key 和历史记录不会随照片发送。详见隐私政策。

为什么拍完照没有自动出结果？

请检查服务地址、视觉模型名称与 API Key；可使用「测试连接（仅文本）」排查。营养标签 OCR 和条码扫描可在没有 AI 配置时使用。

营养值和实际差很多？

份量估计是 AI 识别中最不确定的一环。请在保存前展开草稿卡片，直接修改食物名称、克重和各项营养值。应用会保留每条记录的来源与估计不确定性，修改后的结果只影响你自己。

Apple 健康没有数据？

需要在系统弹窗中分别授权「读取」和「写入」。注意：只有你点击「确认记录」之后，确认过的餐食才会同步到 Apple 健康。删除一条餐食时，应用会尝试清理对应的健康数据。

数据存在哪里？怎么删？

  • 记录保存在设备本地；经授权后，确认的餐食和饮水会写入 Apple 健康。
  • 可以在应用内删除单条记录，或清空全部记录。
  • 可以导出 JSON 备份。已导出的文件需要你自己管理，卸载应用不会删除它。
  • 照片不会保存进记录，也不会进入 JSON 备份。

为什么识别不出来 / 数值明显不对？

复杂中式菜品、混合汤羹和被遮挡的食物最容易识别不准。这类情况建议直接手动填写。应用不会为了给出答案而编造食物名称——如果它不确定，会直接让你补充。
