WHY

为什么不做另一个卡路里计数器

传统记录软件用「监督者」视角审视你的每一餐——数卡路里、打分、亮红叉。Easset 选择站在旁观者的一边：不评判、不监督、不打分，只把生活收进一本好看的手帐。

传统记录 App 的痛点Easset 的解法
「监督者」视角：数卡路里、打分、亮红叉，记录变成自我审视旁观者视角 — 不评判、不监督、不打分，AI 是「老友 / 管家 / 教练」三档切换，语气从温柔到硬核自由选
满屏热量数字，每记一笔都在制造焦虑视觉驱动 — 16 种手绘贴纸 + 真物理重力，把摄入记录变成剪报艺术，数字只藏在二级菜单
吃猛一次就前功尽弃，负罪感让人放弃记录零负罪感 — 「豁出去」模式 0 健康提醒，吃得猛反而发勋章，次日自动切回、轻轻推一条轻食建议，没有说教
AI 建议一刀切：要么唠叨不停，要么完全缺席按需管理 — AI 的深度由你定义，从「老友式的关怀」到「教练级的严苛」，随时一键切换

DEEP DIVE

9 个 SPM 模块的解耦架构

Easset 采用高度模块化架构，9 个 Swift Package 各自独立、可单独编译，为未来跨平台扩展留足空间。模块之间有一条铁律：PortfolioCanvas 不直接 import 业务模块（只准 import DesignSystem），跨模块访问必须走 public API。

SPM 模块职责
DesignSystem视觉系统：8 主色 token、Fraunces/Nunito 字体、16 种手绘贴纸 glyph
DataStoreSwiftData 持久化 + iCloud 同步 + App Group 共享，9 个 @Model 完整 Schema
StickerEngine端侧抠图：MobileSAM 图像分割、图像增强与贴纸生成
AdviceAgent三档模式逻辑与 AI 推荐：generateDailyAdvice 热量建议
PortfolioCanvas手帐画布与拼贴系统，真物理引擎驱动（G=1.12 / REST=0.44 / FR=0.965）
NutritionEngine营养计算：BMR/TDEE 自定义、宏量营养素目标
GoWildMode「豁出去」模式：昼夜双主题、18 枚勋章、死党口吻
HealthSyncHealthKit 联动：Apple Health BMR 数据接入
MedTracker药物日历：10 类药物、35 预定义目录、经期 4 阶段
StrictWidget严厉模式专属 Widget：热量环 / 三环进度 / 营养仪表盘，实时同步
依赖方向：EassetApp 主入口 → 全部模块；AdviceAgent → NutritionEngine；GoWildMode / MedTracker / StrictWidget → DataStore。UI 框架 SwiftUI（iOS 17+），数据层 SwiftData 加密存储，端侧 AI 硬件加速保护隐私。
