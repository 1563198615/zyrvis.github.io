ISLAND
DISTRICTS

岛不岛不是一张漂亮背景图，而是一套能运转的城市。五大分区分别承接健康、生产、商业、公共服务和社交生活。

WEST · NATURAL DISTRICT

农田把饮食
变成收获。

梯田菜园、柑橘果园、奶牛牧场、玻璃温室和清水灌溉网共同组成农业循环。饮食打卡产生种子与食材碎片；涂涂在育苗工坊安排种植，成熟作物进入市集、餐厅和好友宴席。

生产设施温室 / 磨坊 / 堆肥 / 市集

居民故事浇水 / 收获 / 运送 / 交易

EAST · BUSINESS DISTRICT

一座会生活的
海港 CBD。

交易所、银行、创业工坊、诊所、图书馆与渡轮码头围绕步行广场展开。商业不是独立菜单：居民真实上下班，货物从港口进入商店，健康行为形成全服经济的基本面。

核心设施交易所 / 银行 / 工作室 / 商店
交通系统渡轮 / 自行车 / 空中步道
绿色城市太阳能屋顶 / 屋顶花园
三秒玩法行情屏与露天交易广场
NORTH · WELLNESS DISTRICT

健身房没有墙，
运动连着海。

开放式力量区、屋顶跑道、攀岩墙、泳道、瑜伽草坪、恢复诊所和补水站组成一座立体健康中心。训练数据在这里结算为资源，联赛日则沿山路连接上方体育场。

训练设施力量 / 跑步 / 游泳 / 攀岩
恢复设施拉伸 / 理疗 / 补水 / 更衣
社交玩法教练课 / 约练 / 球队联赛
建筑语言玻璃 / 木 / 绿植 / 海景平台
CENTRAL · CIVIC DISTRICT

公共服务，
也是岛上日常。

医院、警局、消防局、法院、邮局和市政厅集中在中心岛。它们不只是布景：健康报告在医院生成，捣蛋案件进入警局与法院，邮差慢慢把好友礼物送上门。
