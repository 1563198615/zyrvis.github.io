WHY

为什么又做一个健康 App？

因为传统健康 App 的路走不通：记录数据 → 生成报告 → 用户流失，30 日留存不到 10%。岛不岛把同一份健康数据，接进了一套让人停不下来的游戏循环。

传统健康 App 的痛点岛不岛的解法
记录数据 → 生成报告 → 用户流失，30 日留存 <10%健康行为 → 获得资源 → 建设世界 → 情感连接 + 社交绑定 → 持续健康行为
有数据无情感，打卡像完成任务不是为打卡而健康 — 是为了岛更繁荣、在朋友面前有面子、球队不输
焦虑式提醒催人自律，越催越烦好友捣蛋的游戏化社交压力替代焦虑提醒；惩罚全是可逆软反馈，不制造焦虑
一个人坚持太难，没人看见你的努力球队联赛把个人自律变成团队责任：你偷懒，全队输；LED 屏、博物馆让健康成果可被炫耀

一人一岛 + 群岛世界：注册即生成自己的岛，好友的岛在你的海图上浮出水面，非好友的岛完全不可见 — 可见性 = 关系深度。岛内有五分区，岛外有交通演进线与跨岛贸易。

生态群系占比特色地形专属资源 / 玩法

山地形15%山峰、悬崖骑行/登山加成，产矿石装饰

地形是「资产」不是「皮肤」：差异是流派不是惩罚（沙漠岛种菜 −20% 但阳光 +100%），后期可用金币购买新地貌地块，但改不了出生地形。

⛵ 跨岛交通演进线 — 从游泳到跨海大桥
阶段交通方式解锁条件能力
初期游泳 / 小船加第一个好友访问好友岛，只能带随身物品
中期快艇 / 帆船金币购买更快访问好友岛，可携带小礼物
中后期飞机建机场（高等级建筑）+ 金币盲盒式随机降落陌生岛，每日航班有限；只能参观点赞，不能捣蛋
后期桥梁双方好友 + 各付 50% 金币共建两岛陆路连通，开车往返 — 桥是「关系的实体化」
高级大桥网络群岛联盟多岛互通，形成「岛国」

不同生态 → 特产不同 → 贸易有真实需求：雪地岛的冰块在沙漠岛是奢侈品；货车货运量上限与车主真实运动数据挂钩 — 健康再次兑换为经济能力。
